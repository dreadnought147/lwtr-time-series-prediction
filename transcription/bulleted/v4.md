- Geraud's framing of research-question discipline: a research question compares one thing with everything else held constant.
- If comparing architectures, hold the learning algorithm and dataset fixed, so the difference is attributable to architecture.
- If comparing supervised learning against RL Frame Stacking, hold the architecture and dataset fixed, so the difference is attributable to the learning paradigm.
- Changing both the architecture and the algorithm means you cannot claim the performance difference comes from RL Frame Stacking — the architecture change may be part of it.
