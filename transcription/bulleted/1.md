1 — first of the numbered recordings

- Geraud points to the Adaptive Stacking paper: on some tasks AS has higher performance than Frame Stacking, which is the whole point of the method — but it is a general tendency, not a guarantee, so you have to experiment.
- PPO + Frame Stacking with the full history generally performs best.
- PPO + Frame Stacking with *less* memory usually performs worse than AS, if AS can learn what to keep.
- Benny confirms he has that result too.
- The argument Geraud says to maintain: full-history FS usually gives the best performance, but not always — because it has the full history it takes longer to learn, so depending on the problem AS with a smaller memory may learn faster.
- If both have full memory, AS should not take longer than FS, since it is handling the same amount of memory and only making a selection.
- Geraud: sounds good so far.
- Benny describes the data: a time series, past 36 years, two data streams.
- Reasoning for not using S&P alone: he wanted a second stream that correlates with the position you'd take on the S&P, to give the memory mechanism something to work with.
- One stream is the observation stream the agent trains on.
- Geraud asks whether the dataset has been used in prior work. Benny has not checked.
- Benny knows S&P is used as the test asset in previous work, for predicting direction against historical S&P.
- Benny admits he used an LLM to help find a dataset that would give some understanding of what the S&P is doing, rather than following S&P blindly. Recording cuts off.
