

**Slide 1 — The Research Question**

Three-way comparison:
- Memoryless RL vs Supervised Learning — does RL itself add value?
- RL with Frame Stacking vs Memoryless RL — does memory help?
- RL with Adaptive Stacking vs RL with Frame Stacking — does *learned* memory beat *fixed* memory?

Core hypothesis: an agent that learns what to remember will outperform one that only remembers the most recent observations.

---

**Slide 2 — Why This Matters**

Most RL memory research uses game environments (Atari). Financial time-series is non-Markovian by nature — the correct prediction at time t depends on events that happened further back than any fixed window can see. This makes it a natural and underexplored testbed for adaptive memory mechanisms.

---

**Slide 3 — Data Choice and Justification**

Chosen series: VIX (CBOE Volatility Index).

What it is: a daily measure of expected market volatility derived from S&P 500 options prices. High VIX = fearful market. Low VIX = calm market.

Why VIX specifically:
- explain vix in a non technical mnnaer in tehse slides the supervisor cares not for our dataset
- Exhibits clear regime-dependent, mean-reverting behaviour
- Well-documented memory structure — spikes decay over days in patterns that depend on the spike's cause and magnitude
- Non-Markovian by nature — recent observation alone is insufficient to predict next move
- Single series keeps the experiment clean and the research question isolated

Observation representation: log returns of VIX, not raw price. Returns are stationary and scale-invariant — standard practice in quantitative finance.

---

**Slide 4 — What the Agent Does**

The environment presents one VIX log-return (explain what this is for a non financial audience please) observation per timestep. The agent predicts direction: up (+1) or down (-1). Reward is +1 for correct prediction, -1 for incorrect. The agent learns a policy that maximises cumulative reward — which means it learns to predict better over time.

This is a prediction task framed as a sequential decision problem.

---

**Slide 5 — The Three Agents**

Agent 1 — Memoryless RL: receives only the current observation. No history. Baseline for whether RL adds anything at all over random.

Agent 2 — Frame Stacking RL: receives the last k observations as a flat vector. Fixed sliding window — oldest observation drops off as new one arrives. Memory is fixed, not learned. This is the standard approach (what DQN used for Atari).

Agent 3 — Adaptive Stacking RL: receives k observations but chooses which slot to overwrite at each step. Memory is a learned decision. Based on Nangue Tasse et al. (2025). Both the prediction action and the memory action are learned through the same reward signal.

---

**Slide 6 — Key Assumption Being Tested**

VIX log-returns are k*-order Markovian — meaning there exists some minimum history length k* beyond which additional history adds no predictive value. The claim is that adaptive stacking can achieve performance equivalent to an agent with full access to that history, using a smaller memory budget, by learning to keep the right observations rather than just the most recent ones.

This is the theoretical guarantee from the Nangue Tasse et al. paper.
